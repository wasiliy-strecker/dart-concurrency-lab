# Changelog

## 0.1.0

- Added six executable labs for Dart event-loop, Future, Stream, isolate,
  cancellation, and Zone behavior.
- Added bounded UTF-8 framing and deterministic NDJSON aggregation.
- Added a long-lived isolate pool with restart and one safe batch retry.
- Added the installable `ndjson_analyzer` CLI with text/JSON output, stable exit
  codes, deadlines, strict validation, and graceful SIGINT handling.
- Added cross-platform CI, coverage, AOT compilation, documentation, and seeded
  correctness-checked benchmarks.
