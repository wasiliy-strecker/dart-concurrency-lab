# Benchmarking

The benchmark compares two implementations of the same pipeline:

- sequential batch parsing on the main isolate;
- a configurable pool of long-lived parser isolates.

It generates a seeded, fixed-shape NDJSON data set in memory, warms both paths,
runs each path repeatedly, and checks that their deterministic reports match
before printing timings.

```sh
dart run benchmark/pipeline_benchmark.dart \
  --events=100000 --runs=3 --workers=4
```

The output records Dart version, OS, processor count, input size, median time,
and events per second. Results are meaningful only with that environment and
input shape attached.

## What it does not claim

- It is not a universal isolate-versus-main-isolate score.
- It does not model disk speed because the generated bytes are in memory.
- It does not assert a speedup; small inputs can correctly favor sequential
  execution.
- CI runs only a smoke-sized benchmark and has no wall-clock threshold.

For application decisions, benchmark representative line lengths, payload
shapes, storage, target devices, and worker counts. Confirm correctness before
interpreting speed.
